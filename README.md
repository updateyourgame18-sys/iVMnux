# iVMnux
iVMnux is an experimental project aiming to run iOS 18+ on x86_64 Linux with a full iOS userspace.
Not an iOS-inspired UI.
Actual iOS userspace running on Linux
Development Status
iVMnux is currently under active development and is not yet released.
The project is currently approaching one of its biggest milestones:
SpringBoard.
Once the userspace is sufficiently complete and SpringBoard is running, the project will be prepared for its first 

public release.
Until then, there’s not much to download here YET.
The Goal
The end goal is to make it possible to run an iOS userspace on an x86_64 Linux host, including the components required to reach a functional iOS environment.

This involves work across:

* Darwin / iOS internals
* x86_64 virtualization and emulation
* Apple system components
* Userspace compatibility
* Boot and runtime infrastructure
* Code signing and trust infrastructure

Release

There is currently no public release.

The repository will be populated as the project reaches a releasable state.

SpringBoard is the target. and I’m getting close
